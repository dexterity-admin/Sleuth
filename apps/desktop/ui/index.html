Settings

Reading PDFs

Shared reading cache (required)

Drawings already read on another PC are not read again here, so everyone shares the work. Use the office folder U:\Sleuth-cache, or another folder on a network drive that all teammates can write to.

Office server (optional)

With an office server, searches also cover the drawings it has read. Leave the address empty to use Sleuth on its own.

Certificate file (optional)

Without a certificate file, Sleuth looks for sleuth-server-ca.pem in the shared cache folder.

Projects

A project is a name for a set of folders. Pick it next to the search box to search only those folders.
